# CineData Analytics - Agente Text-to-SQL

Projeto desenvolvido para a atividade de GenAI do Rocket Lab 26.2.

O objetivo é desenvolver um agente capaz de responder perguntas em
linguagem natural sobre o catálogo de filmes da CineData Analytics,
gerando e executando consultas SQL sobre a camada Gold.

## Tecnologias

- Python
- PydanticAI
- SQLite
- OpenRouter
